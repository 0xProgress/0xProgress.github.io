## 📖 About

This is the source code for my personal portfolio site — a minimal, brutalist‑inspired space where I showcase my work, share my latest activity, and connect with people.

The site is **fully static**, generated from a single HTML file and data fetched from GitHub via a scheduled workflow.

🔗 **Live:** [0xProgress.github.io](https://0xprogress.github.io)

---

## ✨ Features

- **Carousel** — Loops through projects with infinite scrolling, hidden arrows (visible on hover), and animated dots.
- **Commit Feed** — Shows recent pushes with commit messages (resolved via API).
- **Activity Stats** — Displays total commits, project count, and current focus (all sourced from `data/site-data.json`).
- **Adaptive Resume Button** — Automatically disables if `resume.docx` is missing, showing "Résumé (coming soon)".
- **SVG Icons** — Clean, consistent inline SVG icons for socials, stats, and buttons (no emoji fallback).
- **Custom Ink Cursor** — A distinctive, on‑brand cursor experience.
- **Paper Texture** — Subtle grain overlay for a tactile, print‑like feel.
- **Auto‑Generated Data** — `data/site-data.json` is rebuilt every 6 hours via GitHub Actions.

## 🚀 Getting Started

### 1. Clone the repo

```bash
git clone https://github.com/0xProgress/0xProgress.github.io.git
cd 0xProgress.github.io
```

### 2. Run locally

```bash
python3 -m http.server
```

Then visit `http://localhost:8000`.

### 3. Generate test data

Create `data/site-data.json` with sample data (or let the workflow generate it).

## 🔄 Auto‑Generation Workflow

The GitHub Action (`.github/workflows/build-site-data.yml`) runs **every 6 hours** and:

1. Fetches all non‑fork repos from GitHub.
2. Computes total commits via contributor stats.
3. Fetches recent push events and resolves commit messages.
4. Builds `data/site-data.json` with:
   - `projects[]` — name, description, repoUrl, status (Active/Maintenance/Stable), tech, updatedAt
   - `commits[]` — username, repo, message, date
   - `totalCommits` — sum of all commits
   - `currentFocus` — (currently hardcoded to "Golang")
   - `updatedAt` — timestamp of last build

### Manual Trigger

You can also trigger it manually from the **Actions** tab on GitHub.
